## 📌 Project Overview

Meridian is a web-based email management platform developed to simplify communication between executives and personal assistants. It provides an organized workspace for handling email conversations, managing message threads, and tracking important communication updates.

The main goal of this project is to improve communication efficiency, reduce manual effort, and provide a smooth experience through a simple and user-friendly interface.

## 🎯 Project Objectives

- Simplify executive and assistant communication.
- Organize email conversations in one place.
- Improve email thread management.
- Make communication tracking easier.
- Provide a clean and user-friendly interface.
- Increase productivity and reduce manual work.

## ✨ Key Features

- **Email Management:** Manage and organize email conversations.
- **Thread Management:** Keep related email messages organized.
- **Communication Tracking:** Follow important conversation updates.
- **User-Friendly Interface:** Simple and intuitive application design.
- **Centralized Workspace:** Access communication-related information in one place.
- **Productivity:** Make daily email management more efficient.

## ⚙️ Installation and Setup

Follow these steps to run the project locally.

**Step 1: Clone the repository**

```bash
git clone YOUR_REPOSITORY_URL
```

**Step 2: Navigate to the project directory**

```bash
cd Meridian-Executive-Personal-Assistant-Email-Desk
```

**Step 3: Install dependencies**

```bash
npm install
```

**Step 4: Start the development server**

```bash
npm run dev
```

**Step 5: Open the application**

Open the local development URL displayed in your terminal.
